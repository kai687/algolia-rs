# `algolia-rs`

A small CLI for working with the Algolia APIs.

**This is an educational project for me to learn Rust.**

There is an official [Algolia CLI](https://github.com/algolia/cli)
that's properly supported.

## Commands

- [X] `algolia indices list`
- [X] `algolia indices copy`
- [X] `algolia indices move`
- [X] `algolia indices delete`
- [X] `algolia records import`
